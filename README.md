# Macro Recorder (WPF / C#)

Ein kompakter, leistungsstarker und moderner Makro-Recorder für Windows, entwickelt mit WPF und C#. 

## ✨ Features
- **Multi-Monitor-Unterstützung:** Präzise Aufzeichnung und Wiedergabe über den gesamten virtuellen Desktop (inkl. negativer Koordinaten).
- **Intelligente Fenstersuche:** Findet Ziel-Fenster flexibel über Teilstrings oder das erste Wort im Titel.
- **Smart Recording:** Automatisches Debouncing von Mausbewegungen und Erkennung von Leerläufen (`Wait`-Aktionen).
- **Steuerungs-Flow:** Unterstützt globale Hotkeys (`F9` Start/Stopp, `F10` Pause, `ESC` Abbruch) sowie Kontrollstrukturen wie `Jump`, `Repeat` und bildbasiertes Warten via OpenCVSharp (`WaitImage`).
- **Persistenz:** Nahtloses Speichern und Laden von Makros im JSON-Format.
